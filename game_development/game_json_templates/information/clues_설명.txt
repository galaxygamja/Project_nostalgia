clues.json 설명

목적
- 플레이어가 인카운터와 조사에서 획득하는 단서를 정의한다.

항목
- id: 단서 ID.
- name: UI 표시 이름.
- description: 단서 내용 설명.
- source_encounter_ids: 단서를 획득할 수 있는 인카운터 ID 목록.
- tags: 추론 후보 검색과 분류에 사용할 문자열 태그.

처리
1. 인카운터 결과가 단서 ID를 지급한다.
2. 이미 보유한 단서인지 검사한다.
3. 신규 단서를 정보 상태에 추가한다.
4. 관련 추론의 required_clue_ids 충족 여부를 다시 계산한다.
5. 단서 획득으로 활성화되는 인카운터 풀 규칙을 갱신한다.

주의
- 단서 표시 이름이 바뀌어도 ID는 유지한다.
- source_encounter_ids는 실제 인카운터 정의를 참조해야 한다.
