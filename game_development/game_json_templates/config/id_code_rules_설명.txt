id_code_rules.json 설명

목적
- 조합형 ID ABCD_001의 각 문자 위치에 허용되는 코드와 의미를 정의한다.
- ID 유효성 검사의 유일한 기준 파일이다.

주요 항목
- schema_version: 파일 구조 버전. 현재 1.
- data_type: id_code_rules 고정.
- id_pattern: 전체 ID 형식을 검사하는 정규식.
- reserved_sequence: 일반 콘텐츠에서 사용하지 않을 예약 번호. 현재 000.
- unused_code: 사용하지 않는 분류 자리에 넣는 문자. 현재 X.
- data_types: 첫 번째 문자별 데이터 종류와 2~4번째 문자의 허용값.
- name: 해당 첫 문자가 나타내는 데이터 종류.
- positions: 2, 3, 4번째 위치별 허용 문자와 뜻.

예시
- ISBO_001: 인카운터(I), 스토리(S), 기지(B), 1회성(O), 첫 번째 데이터.
- CMEB_001: 캐릭터(C), 주요 인물(M), 기술 전문(E), 기지 소속(B).
- FXXX_001: 세부 분류를 아직 사용하지 않는 시설 데이터.

검사 순서
1. ^[A-Z]{4}_[0-9]{3}$ 형식인지 확인한다.
2. 첫 문자가 data_types에 등록되어 있는지 확인한다.
3. 2~4번째 문자가 해당 positions에 등록되어 있는지 확인한다.
4. 000 예약 번호가 아닌지 확인한다.
5. 전체 프로젝트에서 중복 ID가 아닌지 확인한다.

주의
- 네 문자는 단어의 축약이 아니라 각각 독립적인 분류값이다.
- 배포한 ID는 이름이나 내용이 바뀌어도 변경하거나 재사용하지 않는 것이 좋다.
