locations.json 설명

목적
- 기지 내부와 외부 장소, 연결 경로, 입장 조건을 정의한다.

항목
- id: 장소 ID.
- name: UI 표시 이름.
- category: base_interior, outdoor 등 장소 분류.
- description: 장소 설명.
- connected_location_ids: 직접 이동할 수 있는 인접 장소 ID.
- requirements: 입장에 필요한 플래그, 아이템, 시설 상태 등의 조건.
- encounter_pool_ids: 해당 장소에서 사용할 인카운터 풀 ID.
- tags: 검색과 조건 판정에 사용할 문자열 태그.

이동 처리
1. 현재 장소의 connected_location_ids에 목표 장소가 있는지 확인한다.
2. 목표 장소 requirements를 검사한다.
3. 이동 시간을 행동 또는 별도 이동 데이터에서 계산한다.
4. 캐릭터 위치를 변경한다.
5. 목표 장소의 인카운터 풀을 활성 후보로 사용한다.

주의
- connected_location_ids는 양방향이라고 자동 가정하지 않는다.
- 양방향 이동이 필요하면 두 장소 모두 상대 ID를 명시한다.
