initial_game_state.json 설명

목적
- create_new_game()이 읽을 새 게임의 시작 상태를 정의한다.
- 정의 전체를 중복 저장하지 않고 사용할 ID와 초기 덮어쓰기 값만 연결한다.

항목
- current_time: 시작 day_index와 slot_index.
- commander_id: 책임자로 사용할 캐릭터 ID.
- active_character_ids: 게임에 참여하는 캐릭터 ID 목록.
- resource_values: 자원 ID별 시작 수량.
- facility_states: 시설 ID별 condition, efficiency, operational 시작값.
- character_overrides: characters.json의 default_state 위에 적용할 값.
- initial_task_ids: 시작 즉시 활성화할 업무 정의 ID 목록.
- active_pool_ids: 시작 시 런타임으로 복사할 인카운터 풀 ID 목록.
- inventory: 아이템 ID와 시작 수량.
- clue_ids: 시작부터 확보한 단서 ID 목록.
- deduction_ids: 시작부터 완료된 추론 ID 목록.
- flags: 플래그 키와 시작값.

create_new_game() 처리
1. 모든 정의 JSON을 먼저 로드하고 검사한다.
2. 캐릭터와 시설 default_state를 duplicate(true)로 깊은 복사한다.
3. character_overrides와 facility_states를 적용한다.
4. 자원, 아이템, 단서, 추론, 플래그를 대입한다.
5. initial_task_ids로 런타임 업무 인스턴스를 만든다.
6. active_pool_ids의 원본 풀을 런타임 풀로 깊은 복사한다.
7. 시간표를 연결하고 완성된 GameState를 검사한다.

주의
- 참조한 모든 ID는 해당 정의 파일에 존재해야 한다.
- 정의 파일의 원본 Dictionary와 Array를 직접 수정하지 않는다.
