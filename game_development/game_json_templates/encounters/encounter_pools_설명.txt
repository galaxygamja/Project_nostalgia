encounter_pools.json 설명

목적
- 행동과 환경별 출력 인카운터 목록, 가중치, 추출 정책을 정의한다.

항목
- id: 인카운터 풀 ID.
- name: 풀 이름.
- category: sleep, base_management, outdoor 등 용도.
- draw_mode: 추출 방식.
- reset_policy: 제거된 런타임 풀을 다시 채우는 시점.
- encounters: encounter_id, weight, enabled 목록.
- weight: 상대 추첨 가중치. 0 이상.
- enabled: false이면 현재 추첨 후보에서 제외.

draw_mode
- weighted_with_replacement: 가중치 추첨 후에도 항목을 유지한다.
- weighted_without_replacement: 추첨 후 선택 항목을 런타임 풀에서 제거한다.
- sequential: 배열 순서대로 선택한다.
- shuffle_bag: 전체를 섞어 중복 없이 한 번씩 뽑은 뒤 다시 채운다.

reset_policy
- never: 자동 복구하지 않는다.
- daily: 날짜가 바뀔 때 원본에서 다시 복사한다.
- when_empty: 런타임 풀이 비었을 때 다시 채운다.
- on_action_start: 관련 행동 시작 시 다시 채운다.
- manual: 명시적인 지시가 있을 때만 다시 채운다.

가중치 추출 과정
1. enabled가 true인 항목만 수집한다.
2. 조건 불충족, 완료된 1회성, 쿨다운 항목을 제외한다.
3. 유효 항목의 weight 총합을 계산한다.
4. 총합이 0이면 인카운터 없음으로 처리한다.
5. 0 이상 총합 미만의 난수를 만든다.
6. 배열을 순회하며 가중치를 누적한다.
7. 난수가 누적값보다 작은 첫 항목을 선택한다.
8. without_replacement이면 런타임 배열에서 pop_at(index)로 제거한다.

중요
- JSON에서 읽은 원본 encounters 배열에 pop_at()을 사용하면 안 된다.
- create_new_game()에서 duplicate(true)로 만든 런타임 복사본만 수정한다.
