flags.json 설명

목적
- 게임 전반에서 사용하는 플래그 키, 자료형, 기본값을 정의한다.

항목
- id: 플래그 정의 자체의 조합형 ID.
- key: 다른 JSON과 런타임에서 실제로 사용하는 snake_case 키.
- name: 인간과 UI를 위한 표시 이름.
- description: 플래그가 의미하는 상태 설명.
- value_type: bool, int, float, string 등 자료형.
- default_value: 별도 초기값이 없을 때의 값.

사용 예시
- requirements.required_flags에 generator_access를 넣으면 true일 때만 사용 가능하다.
- effect target을 flag.generator_access로 지정하고 set true를 적용할 수 있다.
- ai_intrusion_level처럼 bool이 아닌 수치 플래그도 사용할 수 있다.

처리
1. 새 게임 상태를 만들 때 모든 정의의 default_value를 복사한다.
2. initial_game_state.json의 flags로 값을 덮어쓴다.
3. 변경 시 value_type과 일치하는지 검사한다.
4. 플래그 변경 신호를 보내 관련 인카운터 풀 조건을 다시 검사한다.

주의
- key는 프로젝트 전체에서 유일해야 한다.
- ID는 정의 참조용이고 실제 조건과 효과 경로에는 key를 사용한다.
